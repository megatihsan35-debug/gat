# Titik Temu — project map (read this first, then open only the file you need)

BAAR 3101 Architectural Design 5, Section 8, KAED IIUM — Megat Muhammad Ihsan.
"Titik Temu — Simpul Rasa Semenanjung": Esplanade Local Commercial Hub, Site C, Jalan Tok Muda Awang Ngah, Temerloh (Lot 10150, 5,370 m²). Futuristic typology.

## Units and coordinates (shared by every folder)
- Site coordinates in metres, x = east, y = north, origin = SW site corner on the road. Site polygon: `model/geom.py` `SITE`.
- Big ring "Gelung Rasa" centre `B`, small ring "Gelung Kecil" centre `S`, both on the QIBLA axis (292.3°), 26.22 m apart. Radii and levels are constants in `model/geom.py`.
- Levels: site ±0.000, plinth +0.900, L1 / roof terrace +5.400, small-ring roof +9.900 (parapet +10.5), ribbon roof +11.200 → +12.900, crown +13.500.

## Key decisions (don't undo without asking)
- v2 (15 Nov 2026, after Crit 1): ONE radial centre C (pole of the buildable area of the site incl. the tennis-court land); concave gates under convex hanging upper floors; 3 floors; wave roof high at Selatan + Utara gates (+16.2), low at Tengah + Timur (+10.2); mast +30 m; façade option A (vertical fins opening at the gates). v1 (`model/`) is the Crit 1 design.
- v3.1 (16 Nov 2026, user's sketch): first floor = inner ring R9.5-15.5 | 1.5 m gap | FREE-STANDING ring bridge R17-20 | 1.5 m gap | outer ring R21.5-26.5; the bridge touches the building ONLY by 4 walkways (3 m) on the gate axes. L2 on the inner ring only. Roof = 3 tiers, each +1.8 m towards the centre, all on the wave (outer W, middle W+1.8, funnel rim W+3.6), clerestories where they overlap. Gaps = opal rooflights over GF rooms (carried by the GF, 50 joint to the bridge), open over the gates. Cores are straight TANGENTIAL stairs in the inner ring (C1 east + lift, C2 north + tank room, C3 = lift 2 SW); outer ring escapes by external stairs S4 (W, radial) and S5 (SE, wraps the drum). Column rings A-F: A 9.5, B 11, C 15.5, D 18.5 (bridge), E 23, F 26.5.
- v3 drawing set: A0 sheets at TRUE scale (a 57 m round building is 570 mm at 1:100, too big for A1 with a title block). East block planned in two radial bands (R12.5-18.5 public / R18.5-23 staff + service) so the toilets are usable (MS 1184); GF + L1 toilets stack. Run `python3 v3/check.py` before rebuilding.
- Interior (study approved 16 Nov 2026, Docs artifact "Titik Temu — Interior Design Study"): host state PAHANG dresses the shared spaces (court, arcade, gates, bridge, WC); guest states: shops A2-1 Pahang, A2-2 Johor, A2-3 Melaka, A2-4 N. Sembilan (kuih), A1-1 Selangor+KL+Putrajaya, A1-2 Perak, A1-3 P. Pinang, A1-4 Kedah (ingredients); cafe G31 Kelantan, reception L21 Perlis, family waiting M14 Terengganu; gallery = all states; surau neutral. One shopfront kit + one unique layer (screen pattern, accent colour, feature back wall, signature display). Crit 1 state palette kept (`interior.ST`), no crests/flags. Shop door = SF1 (1000 clear sliding leaf + fixed display pane) — the old SF 1800 did not fit the 2.1 m front. Signs: BM first, uppercase, heads-up totem maps, gate colours for direction.
- Boards: all text uppercase; drawings at TRUE scale on A3 (plans/sections/elevations 1:200, site plan 1:500); A3 landscape, 5 sheets.
- Mock-up: 1:500, 2 mm greyboard = 1 m contour layer, 5 mm foam for the building. Contours were traced from the user's example-model photo (`mockup/H.npy` = photo→site homography) — approximate.
- Room areas must be read from the A1 plan text, not guessed (gallery 54 m², first aid 18 m²).

- 29 architecture skills from Abhinav Bhardwaj's Skills-Architects (MIT, github.com/Abhinavbwj/Skills-Architects, licence in `LICENSE-skills-architects`): design theory, concept design, building programming/typology, spatial planning, envelope, structure, building services, daylighting, acoustics, materials, sustainability, codes, fire safety, accessibility, construction documentation, `architect-calculator` (Python calculators) and country dossiers. - `.claude/skills/lemo-opuscar/` — Lemomo's Lemo-Opuscar film skill (github.com/lemomo-ai/lemo-opuscar; skill text CC BY-NC 4.0 = non-commercial, student use OK). Makes short films entirely in code in one of 99 styles (e.g. exploded teardown, satellite briefing, LiDAR survey, watercolor). Its `scripts/setup.sh` downloads the style library to `~/lemo-opuscar` on first use; needs Node, ffmpeg, Python (all present in the cloud workspace). Use it for project films / presentation videos.
